# Day 05 - K6 Performance Practice

Ngay: 2026-05-28

Muc tieu hom nay:

- Biet bien JSON summary cua K6 thanh quality gate cho CI.
- Biet tach capacity discovery va regression gate.
- Biet doc metric theo SLO/SLA thay vi chi doc terminal output.
- Biet quyet dinh pass/fail dua tren threshold ro rang.
- Biet viet report ngan gon de giai thich vi sao test fail.

## Bai 1: Chay analyzer tu JSON summary

Dung file moi:

```text
scripts/analyze-k6-summary.js
```

Chay voi ket qua Day 04:

```powershell
$env:SUMMARY_FILE="results/day-04-step-rate-summary.json"
$env:REPORT_FILE="results/day-05-quality-gate-report.md"
$env:FAIL_ON_GATE="false"
npm run analyze:summary
```

Cau hoi can tra loi:

- Gate pass hay fail?
- Metric nao lam gate fail?
- Loi chinh la latency, `429`, `5xx`, hay success rate?

## Bai 2: Doi SLO cho regression gate

Chay lai analyzer voi threshold regression nghiem ngat:

```powershell
$env:MIN_SUCCESS_RATE="0.99"
$env:MAX_RATE_LIMITED_RATE="0.01"
$env:MAX_HTTP_FAILED_RATE="0.01"
$env:MAX_P95_MS="1000"
$env:MAX_5XX_COUNT="0"
$env:FAIL_ON_GATE="false"
npm run analyze:summary
```

Yeu cau:

- Ghi lai gate nao fail.
- Giai thich vi sao Day 04 step-rate khong nen dung lam regression gate hang ngay.
- De xuat file summary nao nen dung cho regression gate.

## Bai 3: Doi SLO cho capacity discovery

Chay analyzer voi threshold de phu hop capacity discovery:

```powershell
$env:MAX_RATE_LIMITED_RATE="0.05"
$env:MIN_SUCCESS_RATE="0.95"
$env:FAIL_ON_GATE="false"
npm run analyze:summary
```

Cau hoi can tra loi:

- Capacity gate co nen cho phep mot it `429` khong?
- Khi nao `429` la expected signal?
- Khi nao `429` la loi nghiem trong?

## Bai 4: Tao report cho rate 5 RPS

Dung summary pass cua Day 04:

```powershell
$env:SUMMARY_FILE="results/day-04-rate-5.json"
$env:REPORT_FILE="results/day-05-rate-5-gate-report.md"
$env:FAIL_ON_GATE="false"
npm run analyze:summary
```

Yeu cau:

- So sanh report step-rate va report rate 5.
- Giai thich vi sao `5 RPS` phu hop hon cho regression.
- Ghi ket luan vao `results/day-05-quality-gate-notes.md`.

## Bai 5: Mo phong CI fail

Chay analyzer voi `FAIL_ON_GATE=true`:

```powershell
$env:SUMMARY_FILE="results/day-04-step-rate-summary.json"
$env:FAIL_ON_GATE="true"
npm run analyze:summary
```

Yeu cau:

- Quan sat exit code.
- Giai thich vi sao CI nen fail khi quality gate fail.
- Giai thich khi nao khong nen fail CI, vi du capacity discovery dang co chu dich tim gioi han.
